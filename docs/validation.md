## 行为审阅场景

以下为规则推演，不是独立 Agent 前向试用或真实项目执行：

| 场景 | 包内规定的处理 |
| --- | --- |
| 只给方案，未批准实施 | 调查并形成可审批材料，停在实施边界 |
| 已批准整个批次 | 沿用审批，范围内连续执行，不逐项请求继续 |
| 只允许 T02 | 完成 T02 与适用检查，不推进 T03 |
| 失败后范围内修复 | 登记尝试，修复后重验判定，保留累计额度 |
| 本期必需真实检查暂无条件 | 保持未满足，提交替代方法，不自行 PASS |
| 真实检查已批准为后续 | 专项保持 NOT_VERIFIED，不阻止本期按约完成 |
| 任务全部 DONE | 仍做整体验收，核对必要交接和实际接收 |
| 后续真实环境未验证 | 按当前事实更新知识，后续补实测结果 |
| 中断或外部结果不明 | 核对工作区 / 进程 / 外部状态，不清零额度或盲目重放 |

下一步：在有明确范围的小需求中试用，观察审批发现问题、需求偏移、修复有效性、验收缺陷、记录耗时与恢复一致性，再根据实际摩擦调整。
